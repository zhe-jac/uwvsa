# UW VSA

Landing page for the UWaterloo Vietnamese Students' Association, built with [Next.js](https://nextjs.org) (React + TypeScript, running on Node.js).

## Getting Started

Install dependencies and run the dev server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the site.

## Project Structure

- `src/app/` — root layout, global styles, and the home page route
- `src/components/` — the landing page sections (`Header`, `Hero`, `About`, `Highlights`, `JoinCta`, `Footer`)

## Notes

- Colors and copy are placeholders inspired by [@uwvsa on Instagram](https://www.instagram.com/uwvsa/) — swap in real event details, socials, and contact info as they're finalized.
- Built with Next.js App Router, TypeScript, and Tailwind CSS.

## Available Scripts

- `npm run dev` — start the development server
- `npm run build` — build for production
- `npm run start` — run the production build
- `npm run lint` — run ESLint
